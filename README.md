New World: Ideas

- Make it more lore focused.
- Have unique interactions between creatures and civilizations.
- A dynamic weather system that affects gameplay and strategy.
- Implement a morality system that influences the player's choices and the world's response.
- Create a rich backstory for each civilization, including their history, culture, and conflicts.
- Create a system where the player's actions can have long-term consequences on the world and its inhabitants.
- Introduce a magic system that is tied to the world's lore and history.
- Create a system where the player can create and customize their own characters, including their appearance, abilities, and backstory.
- implement a dynamic economy that responds to player actions and world events.
- implement a seemless multiplayer experience where players can interact with each other and the world in meaningful ways.
- implement a system where there is a seemless transition between different regions of the world, allowing for exploration and discovery.

📌 Core Project Requirements (80%)
Your project must include all of the following:
Menu System
At least 3 options (ex: “Play Game”, “Show Info”, “Exit”).
Loops
One for loop.
One while loop.
At least one loop that uses break or continue.
Algorithm / Logic
Some decision-making or calculation (not just printing text).
Ex: math formula, searching, or simple processing.
Custom Class
At least one new class with:
Fields (variables)
A constructor
At least 2 methods (one should take parameters or return a value)
Encapsulation
Use properties (get/set) to protect data in your class.
Static Concept
At least one static field or static method.
Code Quality
Clear names for variables, methods, and classes.
At least 2 comments explaining important code.
No run-time crashes (debug before turning in).
README File
A short text file with:
Project name
What your program does
Which features you included
Extendability
Your project must be designed so it can continue to grow.
Examples: a game that could add more levels, a quiz that can store more questions, a simulation that can expand to track more variables.
You will keep developing your program until the last day of the semester.
